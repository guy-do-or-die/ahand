What the guards in `tests/e2e/guards/` found wrong in the app, for wave 6 to fix. One row per
finding. A guard that fails because of the app keeps its test, marked `test.fixme` with one line
naming the row here; when a row is fixed, remove the `fixme` (or the `KNOWN` entry in
`a11y.spec.ts`), run the guard, and write "fixed in …" in the Status column.

Run on 2026-11-20, slot 2, `--dev` (Vite), Chromium 1255, against the worktree as it stood while
the other wave 5 packages were still editing it.
