# SDK and link protocol

This page described the SDK and the link codec of the earlier Core (`payload.ts`, the LiveRoute and
TerminalProof containers, `/h/<id>` links). Both were replaced together with Core. The SDK as it is
now is described in [the SDK](../sdk.md), and the link format in [links](../links.md); the byte
layout itself is the header comment of `packages/sdk/src/link.ts`.
