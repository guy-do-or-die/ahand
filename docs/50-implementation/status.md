# Status

## Built and deployed

The contracts (`contracts/src`, Foundry) are implemented and deployed to Base Sepolia (chain id 84532):

| Contract | Address |
|---|---|
| AHandCore | `0x840c2d884ad2d17c3756c4cc86c84e801a57e811` |
| AHandSignals | `0x9d4ac0e5aa9a11f161c2d5e39a931dde24375b17` |
| AHandWitness | `0x964ec4995d43cc6da4bd9666617b0877012db63a` |

The reward token is Circle's Base Sepolia USDC, `0x036CbD53842c5426634e7929541eC2318f3dCF7e` (6 decimals).

Also built:

- Full Foundry test suite over the contracts — see [testing](testing.md).
- TypeScript SDK (`packages/sdk`) for hashing, signing, link encoding, and verification, with cross-language signature vectors generated by the contracts and replayed byte-for-byte in vitest.
- Web app live at https://ahand.in (Vercel), reading chain state directly over RPC — see [web app](../40-applications/web-app.md).
- Subgraph for AHandCore on Base Sepolia (Graph Studio target `ahand-base-sepolia`) — built, but not yet consumed by the app; see [subgraph](../30-architecture/subgraph.md).
- Local stand (`infra/anvil/stand.ts`): spawns anvil, deploys the contracts, starts a Pimlico Alto bundler with a mock paymaster, and writes addresses into `packages/abi`.
- Base Sepolia seeder (`infra/seed/seed.ts`): raises real pinned Hands (seven scenarios) that fill the public board and landing carousel.

## Not implemented

- Base mainnet deployment.
- `down()` — the signal id and `DOWN_COST` constant are reserved; there is no entrypoint.
- ThankPermit / relayed thank — the typehash exists in AHandTypes; `thank()` is direct and raiser-only.
- CCIP-Read or any on-chain ENS integration.
- Subgraph consumption in the web app.
- Payload encryption — visibility limits discovery; it does not encrypt content.
